# 브릭 타임테이블

계획이 아니라 **방금 한 일**을 쌓아 올리는 기록형 시간표.

표를 드래그해 방금 쓴 시간을 칠하면 그 자리에 레고 브릭이 끼워집니다.
꾸준히 쌓는 것 자체가 보상이 되도록, 브릭이 코인이 되고 코인으로 픽셀 동물을 키웁니다.

## 쓰는 법

- **표를 드래그** → 시간이 자동으로 채워집니다. 할 일만 고르면 끝
  - 마우스는 바로 드래그
  - 손가락은 가로로 끌면 바로, 세로로 길게 칠하려면 잠깐 누르고 있다가 끌면 됩니다
  - 한 칸 그냥 누르면 그 10분만 기록됩니다
- **할 일**은 직접 만듭니다. 기본은 공부·운동·휴식 세 개뿐이고, 자주 하는 일은 추가해 두면 다음부터 한 번만 누르면 됩니다
- 그때그때 달라지는 일정은 **기타 브릭**에 넣고 브릭마다 이름을 따로 붙입니다

## 보상

| | 코인 |
|---|---|
| 브릭 1개 (10분) | +1 |
| 그날 첫 기록 | +5 |
| 하루 목표 달성 | +10 |
| 연속 기록 | 연속일수 × 2 (최대 +30) |

기록이 늘어난 만큼만 지급하므로 지웠다 다시 써도 코인이 불어나지 않습니다.
모은 코인으로 동물 8종을 입양하고, 먹이를 10번 주면 아기 → 청소년 → 어른으로 자랍니다.

## 만듦새

- 빌드 도구 없는 단일 HTML 파일. 외부 라이브러리는 쓰지 않습니다
- 동물은 16×16 픽셀 스프라이트를 캔버스에 절차적으로 그리고 외곽선을 자동 생성합니다
- 기록은 브라우저 저장소에 남습니다. 계정이 필요 없는 대신 기기 간 동기화는 되지 않습니다
- 홈 화면에 추가하면 앱처럼 열리고, 인터넷이 끊겨도 기록을 이어갈 수 있습니다
